# FocusFlow

A student-built Todo List web application using Node.js, Express and Tailwind CSS.

## Features

- Sign up
- Sign in
- Logout
- Add tasks
- Tick / untick tasks
- Delete tasks
- Due dates
- Daily repetition
- Weekly repetition
- Every 2 weeks
- Monthly repetition
- Daily completion streak

## Run

```bash
npm install
npm run dev
```

Open:

http://localhost:3000
